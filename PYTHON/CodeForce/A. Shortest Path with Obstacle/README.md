# Codeforces 1547A - Shortest Path with Obstacle

##Conceptos
- Distancia Manhattan
- Coordenadas
- Condiciones geometricas

## Idea 
La distancia minima sin obstaculos es:
|ax - bx| + |ay - by|

Si A y B estan en la misma fila o columna y F se encuentra estrictamente entre ellos
se deben realizar 2 movimientos adicionales
